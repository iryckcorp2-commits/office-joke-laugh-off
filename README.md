One original one-line joke about office life: My manager said the meeting could have been an email, so I sent an email about the meeting and now we need a meeting to discuss the email.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program writes `entry.txt` (one line, 138 characters) to the output directory. It uses only the Python 3.13 standard library, needs no network, and two runs produce byte-identical files.
